# Stock Portfolio Tracker

## About the Project
This is a simple Python-based Stock Portfolio Tracker developed as part of my CodeAlpha Python Programming Internship.

The project calculates the total investment value based on predefined stock prices and the number of shares entered by the user.

## Features
- Displays available stocks and their prices.
- Allows users to enter stock names and share quantities.
- Calculates individual stock investments.
- Displays the total portfolio investment.
- Handles invalid inputs.
- Saves the portfolio report in a text file.

## Technologies Used
- Python
- Dictionaries
- Loops and Conditional Statements
- Exception Handling
- File Handling

## How to Run
1. Download or clone this repository.
2. Open the project in Python IDLE or VS Code.
3. Run `Stockporfolio.py`.
4. Enter stock names and quantities when prompted.
5. View your total investment and optionally save the report.
